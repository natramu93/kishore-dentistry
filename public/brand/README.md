# Dr. Kishor's Dentistry brand assets

These web assets were derived from the clinic-supplied `Kishor's New Logo.pdf`.
The 52 MB source PDF is intentionally not distributed with the application.

- `kishors-dentistry-logo-on-navy.webp` is the white-and-gold lockup for the
  brand navy surface (`#001A6B`).
- `kishors-dentistry-logo-on-light.webp` is the blue-and-gold lockup for white
  and printed surfaces.
- `kishors-dentistry-mark.png` is the compact tooth-in-hand mark used for app
  icons and constrained placements.

The PDF's lossless 16-bit Photoshop composite was decoded, converted from its
embedded Adobe RGB (1998) profile to sRGB, tightly cropped, and exported without
source metadata. All three assets are intentionally opaque because the supplied
artwork does not contain transparency; the compact mark uses a white background.
